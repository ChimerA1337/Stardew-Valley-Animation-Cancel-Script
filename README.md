# Stardew-Valley-Animation-Cancel-Script
A script for executing animation cancels in the video game Stardew Valley. It uses the pynput library, which works on Windows, MacOS, and also x11 and Wayland Linux. By extension, this script should also work on Windows, MacOS and x11/Wayland Linux.

The timings on this script are very generous, feel free to adjust them.

# Dependencies
- python3, https://www.python.org/downloads/
- pynput, https://pypi.org/project/pynput/
